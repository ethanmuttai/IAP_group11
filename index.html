Voter Edu API

API exposed by Voter Edu to downstream partners for accessing candidate information, policy positions, and candidate reviews. The API supports reading candidate information and creating reviews.
More information: https://helloreverb.com
Contact Info: hello@helloreverb.com

Default

Up 
get /candidates/{candidateId}
Return the full profile of a single candidate (candidatesCandidateIdGet)

Path parameters

candidateId (required)
Path Parameter — Unique identifier of the candidate

Return type

Candidate

Example data

Content-Type: application/json
{
  "id" : "ruto",
  "initials" : "WR",
  "name" : "Dr. William Ruto",
  "party" : "Kenya Kwanza Alliance / UDA",
  "description" : "Current President of Kenya with experience in national government.",
  "experience" : "Current President of Kenya (2022-2026), former Deputy President (2013-2022).",
  "vision" : "The Bottom-Up Economic Transformation Agenda (BETA).",
  "fiscal" : "Expanding the formal tax base to manage public debt.",
  "agriculture" : "Subsidized farm inputs and fertilizer distribution.",
  "governance" : "Protecting and increasing funding to the 47 counties.",
  "cost_of_living" : "Cutting consumer levies and production taxes.",
  "average_rating" : 4,
  "review_count" : 1
}

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

The requested candidate profile Candidate

Example data

Content-Type: application/json
{"id":"ruto","initials":"WR","name":"Dr. William Ruto","party":"Kenya Kwanza Alliance / UDA","description":"Current President of Kenya with experience in national government.","experience":"Current President of Kenya (2022-2026), former Deputy President (2013-2022).","vision":"The Bottom-Up Economic Transformation Agenda (BETA).","fiscal":"Expanding the formal tax base to manage public debt.","agriculture":"Subsidized farm inputs and fertilizer distribution.","governance":"Protecting and increasing funding to the 47 counties.","cost_of_living":"Cutting consumer levies and production taxes.","average_rating":4,"review_count":1}

404

No candidate exists with the given candidate ID Error

Example data

Content-Type: application/json
{"code":"NOT_FOUND","message":"Candidate not found"}
Up 
get /candidates/{candidateId}/reviews
Return all reviews for a candidate, optionally filtered by minimum rating (candidatesCandidateIdReviewsGet)

Path parameters

candidateId (required)
Path Parameter — Unique identifier of the candidate

Query parameters

minRating (optional)
Query Parameter — Return only reviews with a rating greater than or equal to this value

Return type

array[Review]

Example data

Content-Type: application/json
[ {
  "id" : 1,
  "candidate_id" : "ruto",
  "user" : "Anonymous Voter",
  "rating" : 4,
  "text" : "Clear focus on devolution structural systems, but need more clarity on agricultural subsidy time-tables.",
  "date" : "2026-06-25"
}, {
  "id" : 1,
  "candidate_id" : "ruto",
  "user" : "Anonymous Voter",
  "rating" : 4,
  "text" : "Clear focus on devolution structural systems, but need more clarity on agricultural subsidy time-tables.",
  "date" : "2026-06-25"
} ]

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

A list of reviews for the candidate

Example data

Content-Type: application/json
[{"id":1,"candidate_id":"ruto","user":"Anonymous Voter","rating":4,"text":"Clear focus on devolution structural systems, but need more clarity on agricultural subsidy time-tables.","date":"2026-06-25"}]

400

Invalid minimum rating supplied Error

Example data

Content-Type: application/json
{"code":"INVALID_PARAMETER","message":"minRating must be an integer between 1 and 5"}

404

No candidate exists with the given candidate ID Error

Example data

Content-Type: application/json
{"code":"NOT_FOUND","message":"Candidate not found"}

post /candidates/{candidateId}/reviews
Add a new review for a candidate (candidatesCandidateIdReviewsPost)

Path parameters

candidateId (required)
Path Parameter — Unique identifier of the candidate being reviewed

Consumes

This API call consumes the following media types via the Content-Type request header:
  • application/json

Request body

body CreateReviewRequest (required)
Body Parameter —
example: { "user" : "Verified User", "rating" : 5, "text" : "The candidate has clearly communicated their policy priorities." }

Return type

Review

Example data

Content-Type: application/json
{
  "id" : 1,
  "candidate_id" : "ruto",
  "user" : "Anonymous Voter",
  "rating" : 4,
  "text" : "Clear focus on devolution structural systems, but need more clarity on agricultural subsidy time-tables.",
  "date" : "2026-06-25"
}

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

201

Review created successfully Review

Example data

Content-Type: application/json
{"id":2,"candidate_id":"ruto","user":"Verified User","rating":5,"text":"The candidate has clearly communicated their policy priorities.","date":"2026-06-26"}

Missing or invalid review information Error

Example data
