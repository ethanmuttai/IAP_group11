Voter Edu API

API exposed by Voter Edu to downstream partners for accessing candidate information, policy positions, and candidate reviews. The API supports reading candidate information, creating reviews, editing existing reviews, reading civic events, and getting travel advice for an event.
More information: https://helloreverb.com

get /rallies
Return civic events and rallies (ralliesGet)
Sample civic event feed for Group 12 (accessibility and traffic planning). Dates are generated relative to today in Nairobi time (UTC+3), so the feed always contains current and upcoming events. Results are ordered by date. Use upcoming=true to hide events that have already ended.

Query parameters

upcoming (optional)
Query Parameter — When true, return only events that have not ended yet. When false or omitted, return every event in the feed.

Return type

array[Rally]

Example data

Content-Type: application/json
[ {
  "id" : "rally_07",
  "title" : "National Presidential Final Pitch & Mega Civic Mobilization",
  "organizer" : "Consortium of Registered Political Parties & Civic Engagement Forum",
  "candidate" : "Presidential Candidates Joint Civic Appearance",
  "party" : "Multi-Party Civic Initiative",
  "venue" : "Nyayo National Stadium",
  "location" : {
    "lat" : -1.3039,
    "lng" : 36.8242
  },
  "date" : "2026-11-14",
  "startTime" : "10:30",
  "endTime" : "17:30",
  "expectedCrowd" : "40,000+",
  "eventType" : "National Mega Campaign Rally"
} ]

Up 
get /rallies/{rallyId}/travel
Travel advice for getting to a civic event (ralliesRallyIdTravelGet)
Combines our rally data with Group 10's landmarks and rides. Returns the fastest and cheapest ride from the voter's starting landmark to the venue, a crowd-pressure level, a suggested leave-by time and, when the venue is likely to be busy, a walkable alternative drop-off. Everything is an estimate: fares and ETAs reflect current conditions, not the event time, and crowd pressure is a rule-based estimate from expected attendance and the number of ride options, not live demand.

Path parameters

rallyId (required)
Path Parameter — Unique identifier of the rally

Query parameters

from (required)
Query Parameter — Id of the landmark the voter is starting from (from GET /transport/landmarks)

Return type

TravelAdvice

Example data

Content-Type: application/json
{
  "rally" : { "id" : "rally_07", "venue" : "Nyayo National Stadium", "date" : "2026-11-14", "startTime" : "10:30", "endTime" : "17:30", "expectedCrowd" : "40,000+" },
  "from" : { "id" : "1", "name" : "cbd" },
  "rides" : {
    "count" : 3,
    "fastest" : { "providerName" : "Bolt", "rideType" : "Bolt Boda", "fare" : { "amount" : 99, "currency" : "KES" }, "etaMinutes" : 5, "capacity" : 1 },
    "cheapest" : { "providerName" : "Bolt", "rideType" : "Bolt Boda", "fare" : { "amount" : 99, "currency" : "KES" }, "etaMinutes" : 5, "capacity" : 1 }
  },
  "pressure" : { "level" : "high", "expectedCrowdNumber" : 40000, "bufferMinutes" : 60, "reasons" : [ "Expected attendance is 40,000+" ] },
  "leaveBy" : { "date" : "2026-11-14", "time" : "09:25", "basedOnEtaMinutes" : 5, "bufferMinutes" : 60, "leaveNow" : false },
  "alternativeDropoff" : {
    "landmark" : { "id" : "4", "name" : "uhuru park" },
    "distanceKm" : 1,
    "walkMinutes" : 11,
    "savesFare" : 21,
    "savesMinutes" : 1
  },
  "disclaimer" : "Estimates only. Ride fares and ETAs reflect current conditions, not the event time. Crowd pressure is a rule-based estimate from expected attendance and the number of ride options, not live demand."
}
