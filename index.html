Voter Edu API

API exposed by Voter Edu to downstream partners for accessing candidate information, policy positions, and candidate reviews. The API supports reading candidate information, creating reviews, editing existing reviews, reading civic events, and getting travel advice for an event.
More information: https://helloreverb.com

get /rallies
Return civic events and rallies (ralliesGet)
Sample civic event feed for Group 12 (accessibility and traffic planning). Dates are generated relative to today in Nairobi time (UTC+3), so the feed always contains current and upcoming events. Results are ordered by date. Use upcoming=true to hide events that have already ended.

Query Parameter — When true, return only events that have not ended yet. When false or omitted, return every event in the feed.

get /rallies/{rallyId}/travel
Travel advice for getting to a civic event (ralliesRallyIdTravelGet)
Combines our rally data with Group 10's landmarks and rides. Returns the fastest and cheapest ride from the voter's starting landmark to the venue, a crowd-pressure level, a suggested leave-by time and, when the venue is likely to be busy, a walkable alternative drop-off. Everything is an estimate: fares and ETAs reflect current conditions, not the event time, and crowd pressure is a rule-based estimate from expected attendance and the number of ride options, not live demand.

Path parameters

rallyId (required)
Path Parameter — Unique identifier of the rally

Query parameters

from (required)
Query Parameter — Id of the landmark the voter is starting from (from GET /transport/landmarks)

Return type

TravelAdvice

Example data

Content-Type: application/json
{
  "rally" : { "id" : "rally_07", "venue" : "Nyayo National Stadium", "date" : "2026-11-14", "startTime" : "10:30", "endTime" : "17:30", "expectedCrowd" : "40,000+" },
  "from" : { "id" : "1", "name" : "cbd" },
  "rides" : {
    "count" : 3,
    "fastest" : { "providerName" : "Bolt", "rideType" : "Bolt Boda", "fare" : { "amount" : 99, "currency" : "KES" }, "etaMinutes" : 5, "capacity" : 1 },
    "cheapest" : { "providerName" : "Bolt", "rideType" : "Bolt Boda", "fare" : { "amount" : 99, "currency" : "KES" }, "etaMinutes" : 5, "capacity" : 1 }
  },
  "pressure" : { "level" : "high", "expectedCrowdNumber" : 40000, "bufferMinutes" : 60, "reasons" : [ "Expected attendance is 40,000+" ] },
  "leaveBy" : { "date" : "2026-11-14", "time" : "09:25", "basedOnEtaMinutes" : 5, "bufferMinutes" : 60, "leaveNow" : false },
  "alternativeDropoff" : {
    "landmark" : { "id" : "4", "name" : "uhuru park" },
    "distanceKm" : 1,
    "walkMinutes" : 11,

    "savesMinutes" : 1
  },
  "disclaimer" : "Estimates only. Ride fares and ETAs reflect current conditions, not the event time. Crowd pressure is a rule-based estimate from expected attendance and the number of ride options, not live demand."

get /polling-stations/{stationId}/nearest-landmark
Nearest Group 10 landmark to a polling station (pollingStationsStationIdNearestLandmarkGet)
Group 10's rides endpoint only understands its own landmarks, so to compare ride prices to a polling station we find the landmark nearest to it and request rides for that landmark. Prices are therefore for the landmark area, not the exact station. Returns 422 when no landmark is within 15 km. Uses the same saved landmark list as GET /transport/landmarks if Group 10 is briefly unreachable.

Path parameters

stationId (required)
Path Parameter — Unique identifier of the polling station

Return type

NearestLandmark

Example data

Content-Type: application/json
{
  "station" : { "id" : "ps_001", "name" : "Westlands Primary School", "area" : "Westlands" },
  "landmark" : { "id" : "2", "name" : "westlands", "location" : { "lat" : -1.2673, "lng" : 36.811 } },
  "distanceKm" : 0.1
}

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

The nearest landmark NearestLandmark

404

No polling station exists with the given id Error

Example data

Content-Type: application/json
{"code":"NOT_FOUND","message":"Polling station not found"}

Example data

Example data

Object The event.

Object The landmark the voter starts from.
example: id 1, name cbd

Object Usable ride options (capacity 0, such as parcel delivery, is ignored). fastest and cheapest are Ride objects, or null.
example: count 3, fastest, cheapest
pressure
Object Rule-based estimate: attendance sets the base level (under 1,500 low, 1,500 to 4,999 medium, 5,000 and over high), raised one level if rides look scarce.
example: level high, expectedCrowdNumber 40000, bufferMinutes 60, reasons
leaveBy
Object Event start minus the fastest ride ETA minus the buffer (Nairobi time).
example: date 2026-11-14, time 09:25, basedOnEtaMinutes 5, bufferMinutes 60, leaveNow false
alternativeDropoff
Object A walkable landmark 0.4 km to 2 km from the venue that is at least 15% cheaper or 3 minutes quicker. Only for medium or high pressure; otherwise null.
example: landmark, distanceKm 1, walkMinutes 11, fastest, cheapest, savesFare 21, savesMinutes 1
disclaimer
String
example: Estimates only.
